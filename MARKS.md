# Отчет о реализации задач из TASK.md

Этот документ содержит список задач, которые были реализованы не полностью или с отклонениями от `TASK.md`.

## 4.3. Флоу 1: создание заказа + резерв стока

**Статус**: Частично реализовано.

*   **Проблема**: Отсутствует проверка и резервирование стока.
*   **Детали**:
    *   В `OrderService.createOrder` нет логики для проверки `stock_levels` перед созданием заказа.
    *   Не реализован возврат ошибки `422 INSUFFICIENT_STOCK` с деталями о нехватке товара.
    *   В транзакции создания заказа отсутствует обновление `stock_levels` (уменьшение `available` и увеличение `reserved`).
*   **Проблема**: Маршрут API не соответствует спецификации.
*   **Детали**:
    *   Реализован маршрут `POST /orders`.
    *   Требуемый маршрут: `POST /api/tenants/:tenantId/orders`.

## 4.4. Флоу 2: отгрузка заказа

**Статус**: Частично реализовано.

*   **Детали**:
    *   Реализован маршрут `POST /orders/:orderId/ship`.
    *   Требуемый маршрут: `POST /api/tenants/:tenantId/orders/:orderId/ship`.

## 4.5. Флоу 3: возвраты (async через очередь)

**Статус**: Частично реализовано.

*   **Проблема**: Маршрут API не соответствует спецификации.
*   **Детали**:
    *   Реализован маршрут `POST /returns`.
    *   Требуемый маршрут: `POST /api/tenants/:tenantId/returns`.
*   **Проблема**: Не проверены настройки ретраев для очереди.
*   **Детали**:
    *   В `TASK.md` требуется настройка ретраев с backoff и обработка задач, которые упали N раз подряд. Эта логика не видна в коде воркера и должна быть проверена в конфигурации модуля BullMQ.

## 4.7. Простейшая безопасность / tenant-контекст

**Статус**: Частично реализовано.

*   **Проблема**: Проверка `tenantId` в `TenantAuthGuard` не будет работать.
*   **Детали**:
    *   Гвард пытается сравнить `tenantId` из API-ключа с `tenantId` из параметров URL (`request.params.tenantId`).
    *   Однако, все защищенные эндпоинты (`/orders`, `/returns`, `/audit/verify`) не содержат параметр `:tenantId` в своем пути. Из-за этого проверка `paramTenantId && paramTenantId !== tenantId` никогда не выполнится.

## 4.8. Immutable audit (hash-цепочка)

**Статус**: Частично реализовано.

*   **Проблема**: Маршрут API не соответствует спецификации.
*   **Детали**:
    *   Реализован маршрут `GET /audit/verify`.
    *   Требуемый маршрут: `GET /api/tenants/:tenantId/audit/verify`.

## 4.9. Логи и метрики

**Статус**: Частично реализовано.

*   **Проблема**: Неполное логирование.
*   **Детали**:
    *   `HttpLoggingMiddleware` не логирует `tenant_id` для запросов.
*   **Проблема**: Отсутствуют требуемые бизнес-метрики.
*   **Детали**:
    *   Эндпоинт `/metrics` существует, но возвращает только общую информацию о процессе (uptime, memory).
    *   Не реализован сбор и возврат метрик: `orders_created_total`, `webhook_errors_total`, `returns_failed_total`, `returns_queue_size`.
